HTML - CSS - JavaScript

• As bases do Front-End: estrutura, estilo e interatividade. Com essas três tecnologias eu construo interfaces responsivas, acessíveis e com boa experiência de uso.

• Comecei minha jornada dominando fundamentos, porque eles fazem diferença em qualquer projeto, com ou sem frameworks.

• Entender o “por trás dos panos” me ajuda a escrever código mais limpo, manterável e pronto para evoluir.

Angular - Bootstrap - React.JS

• Após consolidar os fundamentos, passei a aplicar frameworks e bibliotecas para ganhar produtividade e organizar melhor a arquitetura do front-end.

• Utilizo componentes reutilizáveis, boas práticas de organização e padrões que facilitam manutenção e evolução do projeto.

• Cada ferramenta tem seu papel: do layout responsivo à construção de aplicações mais completas e escaláveis.

Python - SQL - PowerBI

• Para o Back-End e dados, venho estudando Python e SQL, aplicando conceitos como CRUD, integração com banco de dados e manipulação de informações.

• Também utilizo Power BI para transformar dados em dashboards claros, com indicadores e visualizações úteis para tomada de decisão.

• Meu objetivo é conectar aplicações e dados de forma consistente, com foco em qualidade, organização e valor para o usuário.
